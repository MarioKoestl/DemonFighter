# Asset Pipeline

Nobody on this project models in Blender, and Claude Code cannot create 3D models, textures or animations. The plan is built around that.

## Stages

1. **Primitives (M0 to M4).** Capsules, spheres and cubes with flat colors. Color encodes tier, size encodes mass. Everything about gameplay is built and tested on these. Nothing in the code may depend on a specific mesh.
2. **AI-generated assets (M5).** Text-to-3D and image-to-3D tools produce meshes and PBR textures for the core blob and each body part. Expect cleanup work.
3. **Polish (M6 and later).** Commissioned or purchased assets for anything the generated ones cannot deliver. Asset Store packs for gore, VFX and audio.

## Placeholder standard (stage 1)

- Core: capsule, 1.2 m tall for Tier 0. Scale with tier.
- Parts: cubes or stretched capsules attached to socket transforms. Arm: 0.6 m box. Legs: two 0.5 m capsules. Hide: a slightly larger transparent shell.
- Colors: player a fixed teal; AI demons by tier (0 gray, 1 olive, 2 rust, 3 dark red, elders near black).
- Damage: wounded part darkens and shrinks to 80 percent; severed part detaches with its own collider and rigidbody.
- Blood: a flat round decal, two sizes.

All placeholder prefabs are generated by the `Demon Fighter > Generate > Placeholder Prefabs` menu so they can be regenerated after changes.

## AI-generated 3D assets (stage 2)

Candidate tools, as of late 2026 (check current terms before use; they change often): Meshy, Tripo, Rodin (Hyper3D), Luma Genie. Also Unity's own AI features inside the editor. Mario tries two or three with the same prompt and picks by result quality and license.

Workflow per asset:

1. Write a short brief in `ArtSource/briefs/<asset>.md`: what the part is, which socket, approximate size, style reference words (wet, veined, chitin, raw muscle). Include a reference image if one was generated.
2. Generate. Export GLB or FBX with PBR textures (base color, normal, roughness, metallic).
3. Check: triangle count within budget, textures at the target resolution, the pivot at the attachment point, forward axis +Z, up axis +Y, scale in meters.
4. If the tool offers retopology or decimation, use it. If the result is a mess, try another generation before trying to fix it.
5. Import into `Assets/_Project/Art/Models/<Category>/`. Set import settings per the table below.
6. Record the asset in `docs/ASSET_LICENSES.md`: tool, date, plan, license terms, commercial use allowed yes or no, link to the terms.
7. Keep the source files (GLB, textures, prompt, seed) in `ArtSource/` next to the repository on Mario's PC. `ArtSource/` is gitignored for now because GitHub Free has LFS quotas (see `DECISIONS.md` D-021). Back it up separately.

Known limitations to plan for: generated meshes have messy topology and rarely deform well. That is fine for a blob and for rigid parts (jaws, plates, spines). For arms and legs expect to either accept stiff animation or use procedural animation (see below). Modular parts need a consistent scale; always generate with the core model's size as the reference.

## Modular body parts

- One mesh per part, pivot at the socket, +Z pointing away from the body.
- Naming: `BP_<Part>_<Variant>` for the model, matching the ScriptableObject id `part.<part>.<variant>`.
- Each part ships with damage states as separate meshes: `_Intact`, `_Wounded`, `_Mangled`, and `_Stump` for the body-side remainder after severing. Generated as variants of the same prompt, or by editing in a mesh tool if someone learns one.
- Socket positions are defined on the core model as empty transforms named `Socket_Head`, `Socket_LimbL`, `Socket_LimbR`, `Socket_Locomotion`, `Socket_Hide`, `Socket_Tail`. The `DemonView` finds them by name.

## Animation

- Blob core (v1): procedural. Squash and stretch on movement, a contraction on Bite, a wobble on damage. Code, no clips.
- Limbed bodies: Mixamo (Adobe) can auto-rig humanoid-ish meshes and provides free animation clips; check the current license. For non-humanoid shapes, Unity's Animation Rigging package with procedural IK is the fallback.
- Attack timing (active frames of hitboxes) is data on the skill, not baked into clips, so placeholder and real animations use the same numbers.

## Gore assets

- Blood: decal textures (splats, drips, pools) at 1024 px, used with URP Decal Projector.
- Size range: every body asset must read well from 1 meter to 15 meters, so textures use tiling detail rather than a single baked resolution, and parts come in the same proportions at every size step (the view scales them).
- Viscera: a handful of small generic meshes (strands, lumps) spawned on severing and death, pooled.
- Wound shader: a URP shader with a mask input that darkens and wets the base color near wounds. Mario or Claude Code writes it in Shader Graph or HLSL in M5.
- Asset Store gore and blood packs are allowed; license note required.

## Music

AI-generated. Candidate tools change quickly; Mario picks one, checks that the terms allow commercial use in a game, and records each track in `docs/ASSET_LICENSES.md` with prompt, tool, date and terms. Keep stems or at least the raw export in `ArtSource/music/`.

## Budgets (v1)

| Asset | Triangles | Textures |
|---|---|---|
| Core blob | 8k | 2048 set |
| Body part | 2k to 5k | 1024 set |
| Elder (whole) | 40k | 4096 set |
| World feature | 1k to 3k | 1024 or atlas |

Add LOD levels when a run has more than 30 demons on screen (M5).

## Import settings

- Models: scale factor 1, read/write off, generate colliders off (we add our own), mesh compression off for parts that deform, on for rigid features.
- Textures: sRGB for base color only; normal maps marked as normal; max size per the budget table; compression BC7 for color, BC5 for normals.
- Animation clips: loop time set for locomotion, root motion off (code drives movement).

## Licensing log

`docs/ASSET_LICENSES.md` holds one entry per asset or pack:

```
## <asset or pack name>
- Source: <tool, store, or person>
- Date: YYYY-MM-DD
- License: <name and link>
- Commercial use: yes / no / with attribution
- Attribution text (if required): ...
- Files: Assets/_Project/Art/...
```

Nothing ships without an entry. This is what Steam and a publisher will ask about.
